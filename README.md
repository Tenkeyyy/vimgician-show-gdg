# 🧙‍♂️ The Vimgician Show

**The Vimgician Show** is a live demo project built for **GDG Algiers** that showcases how to build a
Vim-powered, in-browser code editor using **CodeMirror 6** and the **TypeScript Language Service** —
without any backend or LSP server.

## ✨ Features

- 📝 CodeMirror 6 editor
- ⌨️ Full Vim mode
- 🔍 Go-to-definition (`gd`) , JumpBack (`Ctrl-o`) , JumpForward (`Ctrl-l`)
- ⚠️ Real-time diagnostics
- 🧠 Client-side TypeScript intelligence
- 🗂️ Virtual in-memory file system
- 🌙 One Dark theme

## 🧪 Status

🚧 Demo / Educational project — not production-ready.

Built with ❤️ for **GDG Algiers**.
